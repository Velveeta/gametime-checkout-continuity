behavior, not just that code was inspected. **Partial** identifies an external

## Deliberate limits

Local guarantees assume the durable Redis dataset is intact and non-evicting.
Reset intentionally replaces the entire synthetic namespace. No throughput/SLA,
real payment safety, hosted availability, physical accessibility certification,
or deployed behavior is inferred from these tests. See [validation results](VALIDATION.md)
and [remaining deployment steps](DEPLOYMENT.md).
