# Wave 04 — polished responsive shopping and checkout

**Read:** `AGENTS.md`, this wave, latest handoff.

Build polished, accessible event browse page `/`, event detail `/events/[id]` with listing/seat/quantity selection, checkout `/checkout/[id]`, and refreshable post-booking confirmation. Single canonical responsive checkout URL; desktop two-column summary/form, mobile stacked layout, no separate `/m` route. Use Tailwind 4 + shadcn/ui/Radix + Lucide. Keep Server Component event/checkout summary visible before hydration; small client components for actions and updates. No real card data: clear 'Simulated payment' control. Show synthetic prices/fees transparently. Responsive typography, focus/keyboard states, skeletons, error recovery, status announcements.

Display reservation countdown derived from server-provided `reservationExpiresAt` and `serverNow`, locally ticking every second and periodically resynchronized; TanStack Query polls authoritative state ~2s while active and on tab focus. All devices see same deadline. Countdown zero on an **already-open** page triggers authoritative status fetch and redirects to event (not recover); background tabs also check on focus. New navigation to expired checkout follows SSR recovery redirect. Price increase blocks with explicit new-total acknowledgment; decrease shows 'Your tickets just got cheaper!' and auto-applies. Pending processing shows spinner, disabled repeat action; transient failure allows retry with attempt count; definitive decline and exhausted retries show terminal error. Local completion navigates to capability-protected confirmation; other clients observing completion navigate home. Never render completed checkout again.

Make cross-device demo obvious: copy checkout URL, optional QR code if lightweight. Catalog must reflect reserved/expired/sold availability via polling. Distinguish another independent cart from a second view of same session. Preserve URL and refreshability. Tests for SSR first paint content, responsive layouts, accessibility essentials, countdown and cross-client state. Handoff `handoffs/04-ui.md`.
